# Data package (reviewer-facing)

This folder contains the anonymized experimental dataset aligned to the public `experiment_suite` task architecture (TP01–TP08, variants A/B, sequences A–D).

## Files

| Path | Description |
|---|---|
| `AI_NET_Experimental_Dataset_SuiteAligned.xlsx` | Excel workbook for convenient reviewer inspection |
| `csv/observations_master.csv` | Primary analysis table (960 rows) |
| `csv/participants_baseline.csv` | Baseline experience / AI familiarity |
| `csv/sessions_summary.csv` | Session-level summaries |
| `csv/task_pairs_master.csv` | Task-pair metadata |
| `DATA_DICTIONARY.md` | Variable definitions and provenance notes |

## How this relates to the code suite

- **Task IDs** in the data (`TP01`–`TP08`, variants A/B) match folders under `Tasks/`.
- **Hidden-test scoring model** is implemented in `Tasks/TP0x/{A\|B}/Evaluation/`.
- **Static-analysis configuration** is frozen under `analyzer/` (config hash `c84cde8e4805433f`).
- Outcome values in these files are the cleaned empirical observations used for analysis; they are **not** regenerated by re-running the public reference oracles.

## Legacy workbook
